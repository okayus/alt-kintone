## 概要

フェーズ6の仮想スクロール一覧に、セル編集を足す:

- セルのフォーカスモデル（クリック・矢印キー・Tab / Shift+Tab で移動。状態は `{行, 列}` 1つ）
- **Enter で編集開始 → セル位置に実 `<input>` / `<select>` をマウント → Enter 確定 / Esc 取消**
- 確定 = `PATCH` 1回 = 有効期間型の1バージョン（行単位の保存ボタンは持たない）
- 型別セルエディタ（text / integer → input、enum → `{key, label}` の select、
  date / yearMonth → 対応 input。候補とラベルは定義から取る）
- 編集不可セルの表現: `_permissions.record.write` が false の行 / 計算列・フロー列
  （自社収益・現在ステップ・未確認件数）/ v1 では FK セル（付け替えは詳細フォームに残す）
- 確定成功 → レスポンスの行で置換 + 世代を進める（phase-6 論点B）
- 競合は v1 では現状の 409 のみ（根拠は phase-6 論点F。precondition 方式は必要になってから）

## 完了条件（候補。着手時に確定する）

1. セルを矢印 / Tab で移動し、Enter → 編集 → Enter で確定できる（Esc で取消）
2. 確定が `PATCH` になり、**未確認件数のセルがその場で変わる**（例: 金額を入れると
   金額系の自動判定が充足に変わる）
3. 日本語入力（IME）の変換確定の Enter が、セル確定として誤発火しない
4. 担当外の行のセルは編集に入れない（見た目でも分かる）
5. enum セルは定義のラベルで表示・選択され、保存は key で行われる
6. 編集が版として残り、`as_of` で編集前の一覧が読める（既存機能の退行確認）

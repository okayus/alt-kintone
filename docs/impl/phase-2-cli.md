## タスク概要

### 2-1. `alt validate`

`condition-ast.md` §5-4 の3層のうち、**最小スコープでは構文と参照整合まで**。

| 層 | 最小スコープで作るか |
|---|---|
| 構文（zodスキーマに合致するか） | 作る |
| 参照整合（バインド先・フィールド・遷移先が実在するか） | **作る**。`resolveFieldPath` / `foreignKeysTo` が既にある |
| 業務ルール（出口条件のないステップ、孤立テーブル、primaryバインドが2つ） | 後回し可。ただし安いので入れてもよい |

エラーメッセージは**AIが読んで直せる形**にする（どのファイルの何が、なぜ、どう直すか）。
ここが AI の自己修正ループを閉じる部分。

### 2-2. `alt apply`

定義 → SQLite にスキーマを適用する。`packages/sql/src/ddl.ts` が既にあるので薄い。

- 業務テーブル（定義から）+ プラットフォームテーブル（`_flow_state` / `_manual_check`）
- 最小スコープでは**差分適用を作らない**。作り直しでよい（プロトタイプ段階でデータを守る必要がない）
- `alt plan` は作らない

## 完了条件

- `alt apply` でローカルの SQLite にスキーマができ、テーブルとインデックスが揃う

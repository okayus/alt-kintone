# ドメイン調査レポート: kintone内製化提案の前提調査

- 調査日: 2026-06-12（Web調査。価格は特記なき限り**税抜**）
- 目的: 客先（求人広告・飲食店向けMEO等のIT商材を販売する営業会社）が CRM/SFA として利用中の kintone を、内製Webアプリで置き換えるコスト削減提案の土台を作る
- 前提: 社内利用のみ・低トラフィック。kintoneは商談記録などCRM/SFA用途。「フィットしていない」という現場感あり

---

## 1. クライアントの業界ドメイン（求人広告 × 飲食店MEO営業）

### 1-1. 2商材は収益構造が根本的に異なる

| | 求人広告 | MEO対策 |
|---|---|---|
| 収益型 | **フロー型**（掲載単位）→ 運用型へシフト中 | **ストック型**（月額サブスク） |
| 課金形態 | 掲載課金 / クリック課金（Indeed CPC 100〜300円）/ 成果報酬 | 月額固定 1〜5万円/店舗 or 成果報酬（上位表示日額 500〜2,000円） |
| 価格相場 | バイト媒体: 1週間 2〜10万円。Indeed運用は月予算10〜30万円×手数料20% | 飲食店は月額3〜5万円が目安。初期費用 0〜5万円 |
| 契約期間 | 週単位〜（高回転・再掲の繰り返し） | **最低6〜12ヶ月縛り**が一般的 |
| 営業会社の収益源 | 媒体マージン（広告費の10〜30%） | 月額×店舗数のMRR。代理店マージン20〜40% or OEM仕入れ |
| 更新イベント | 掲載満了ごとの再掲商談 | 最低契約期間明けの継続/解約 |

- **2025年の構造変化**: タウンワーク休刊（2025年3月）と Indeed PLUS への移行で、求人広告は「枠売り（定額掲載）」から「運用型（予算×手数料率）」へシフト。契約データには両形態を持てる必要がある（[内藤一水社](https://www.naito.jp/knowledge/jobad/2189/)、[データビート](https://www.data-be.at/magazine/indeed-cost/)）
- **MEOの解約パターン**: 「初月〜3ヶ月で効果確認 → 4〜6ヶ月で頭打ち → 7ヶ月目以降に解約集中」が典型。解約率・継続率の管理がストック収益の生命線（[Digital Port](https://axone.co.jp/digitalport/meo-agency-profitable-products-cost-choice-success/)）
- **業界の評判リスク**: 「Googleを装う営業電話」問題や違約金トラブルが業界課題。まともな業者ほど契約書面・解約条件・運用範囲（口コミ返信の責任分界）・GBP権限の明文化を管理したい動機が強い（[国民生活センター](https://www.kokusen.go.jp/t_box/t_box-faq/i-3.html)、[アシスト](https://assist-all.co.jp/column/meo/20250205-3846/)）

### 1-2. 営業プロセス（典型フロー）

```
リスト作成（HRogリスト等の掲載企業リスト）
  → テレアポ（1日100件規模、アポ率 BtoB 0.5〜3%）
  → 商談（中小店舗オーナー相手の即決型・1〜2回が主流）
  → 受注
  → 納品（求人: 原稿作成・入稿・掲載開始 / MEO: GBPオーナー確認・初期設定・KW設定）
  → 運用・フォロー（求人: 応募効果ヒアリング・再掲提案 / MEO: 投稿・口コミ返信・月次レポート）
  → 更新 or 解約
```

顧客像: 中小飲食店の店長・オーナー、中小企業の採用担当。低単価・高回転・件数積み上げ型の営業組織。

### 1-3. 追うべきKPIと管理項目（＝内製CRMの要件の種）

- **活動ファネル**: 架電数 → 接続率 → アポ率 → 商談化率 → 受注率（担当者別）
- **収益KPI**:
  - 求人（フロー）: 媒体別売上、客単価、リピート率/再掲率
  - MEO（ストック）: MRR、月次解約率（SMB向けサブスクの目安 3〜7%）、平均継続月数、LTV
- **顧客・案件属性**:
  - 共通: 店舗名/企業名、業種・業態、エリア、決裁者、流入経路
  - 求人: 募集職種、出稿媒体、広告プラン、掲載開始/終了日、原稿進捗、ヨミ確度
  - MEO: 契約プラン（固定/成果報酬）、対策キーワード（4〜12個）、GBP権限の所在、契約期間・更新日、解約条件・違約金
- **MEO月次レポート指標**: 検索順位、表示回数（直接/間接）、ルート検索数、電話タップ数、サイトクリック数、予約数（[TOCソリューションズ](https://toc-solutions.net/column/meo-kpi-design/)、[Gyro-n](https://www.gyro-n.com/meo/monthly-report/)）

### 1-4. ドメインモデルへの示唆

エンティティ候補: **顧客（企業/店舗）・担当者・リード・商談（ヨミ管理）・契約（フロー型掲載 / ストック型サブスクの2形態）・活動履歴**。将来的に請求連携。

実在の参考例: リクルート系求人広告代理店ロケットスタートHDは kintone で「ヨミ管理 → 受注 → 原稿作成・入稿進捗 → 実績管理」を一気通貫化（[サイボウズ公式事例](https://kintone-sol.cybozu.co.jp/cases/rokectstartholdings.html)）。求人広告営業の商談は受注後に「制作・入稿」工程へ続くのが特徴で、純粋なSFAより一歩広い。

## 2. kintone の現状理解（置き換え対象）

### 2-1. 料金（2026年6月時点・公式・税抜）

| | ライト | スタンダード | ワイド |
|---|---|---|---|
| 月額/ユーザー | 1,000円 | 1,800円 | 3,000円 |
| 最低契約 | 10ユーザー | 10ユーザー | 1,000ユーザー |
| プラグイン・外部連携・API | **不可** | 可（1万req/日/アプリ） | 可 |

出典: [kintone公式料金](https://kintone.cybozu.co.jp/price/)

- **CRM/SFA用途は実質スタンダード必須**（プラグイン・連携サービスがライトでは使えない）→ 最低でも月18,000円・年21.6万円
- **値上げ実績**: 2024年11月適用で ライト780→1,000円（+28%）、スタンダード1,500→1,800円（+20%）、**最低契約 5→10ユーザー**（[サイボウズ公式](https://topics.cybozu.co.jp/news/2024/05/30-18782.html)）
- **⚠ 2026年11月トピック**: 10ユーザー未満の既存契約の経過措置が**2026年10月末で終了**。11月以降は10ユーザー分の料金に自動切り替え（[サイボウズ公式](https://page.cybozu.co.jp/-/price-revision/)）。クライアントが10人未満契約なら、まさに今が提案の好機

### 2-2. CRM/SFAとしての典型構成

公式「SFA（営業支援）パック」= 顧客管理・担当者管理・案件管理・活動履歴の4アプリ構成。ルックアップ／アクション／関連レコード一覧／プロセス管理で連携（[公式ヘルプ](https://jp.kintone.help/k/ja/app/setup/create_app/sales_pack.html)）。

定番の有料プラグイン・連携サービス（不足機能の補完）:

| 製品 | 用途 | 費用 |
|---|---|---|
| krewSheet | 一覧のExcel風一括編集 | 年27.5万円（税込） |
| krewData | アプリ横断集計バッチ | 年13.2万円〜（税込） |
| krewDashboard | 営業ダッシュボード | 年13.2万〜22万円（税込） |
| FormBridge | 外部フォーム→リード登録 | 月1.2万円〜 |
| kMailer | 顧客へのメール送信 | 月1.8万円〜 |
| PrintCreator | 見積書・請求書PDF | 月7,000円〜 |
| メールワイズ | 顧客メール共有 | 月600円/人 |

→ **本体より周辺サービスの方が高くなる構成も珍しくない**。

### 2-3. 「CRM/SFAとしてフィットしない」と言われる典型理由（提案の論拠）

1. **集計・レポートが弱い**: アプリ横断のクロス集計が標準不可、担当者別の細かい営業分析に非対応（[Mazrica比較記事](https://mazrica.com/product/senseslab/tool-reviews/kintone-sfa/)）
2. **一覧性・UIの分断**: アプリごとに画面とデータが分断され、一連の業務で複数画面を往復。Excel風の一括編集はプラグイン頼み（[Salesforce移行事例の理由](https://www.iftc-svc.co.jp/case/salesforce_case_07.html)）
3. **重複管理・名寄せが標準不可**: 複合条件（会社名+電話番号）の重複検知はプラグイン必須
4. **顧客へのメール送信が標準不可**: kMailer/メールワイズの追加契約前提
5. **SFA専用設計ではない**: 「営業力強化が目的なら専用SFAを使うべき」とSFAベンダー側が共通して指摘
6. **解消しようとするとプラグイン費が積み上がり**、専用SFAと総額が逆転し得る

補足（公平性のため）: Web上では逆方向（Salesforce→kintone、コスト目的）の移行事例の方が多い。kintoneが「安い」のは事実で、提案はコスト単独ではなく「フィットしない問題の解消」とセットで組む必要がある。

## 3. 内製化の論点

### 3-1. コスト比較フレーム

**kintone側TCO（年額）** = ライセンス（1,800円×人数×12）+ プラグイン + 構築・カスタマイズベンダー費（小規模改修10万〜、本格カスタマイズ100万円〜）

| 人数 | 本体のみ/年 | プラグイン2〜3個併用時/年（目安） |
|---|---|---|
| 10人 | 21.6万円 | 30〜50万円 |
| 20人 | 43.2万円 | 55〜80万円 |
| 30人 | 64.8万円 | 80〜110万円 |

**内製側** = 初期開発（工数）+ インフラ + 保守

低トラフィック社内アプリのインフラ費（2026年時点）:

| 構成 | 月額 |
|---|---|
| Cloudflare Workers Free（+D1） | **0円**（10万req/日まで） |
| Cloudflare Workers Paid + D1 | $5〜 |
| Supabase Free / Pro | 0円 / $25 |
| VPS（ConoHa/さくら）・AWS Lightsail | 500〜1,500円 |

→ **ランニングコストは kintone の 1/10 以下**（ドメイン代 年1,500円前後等の細目は別途）。

**成立条件の注意**: 内製の初期開発を外注スクラッチ相場（CRM 400万円〜）で見積もると回収不能。**AIコーディング前提の少工数開発**が前提条件。先行事例として LIG（非エンジニアが約2ヶ月で基幹システム内製、[LIGブログ 2026-03](https://liginc.co.jp/678305)）、ソラコム（生成AIで1日で社内SaaS置換、[ASCII 2025-10](https://ascii.jp/elem/000/004/323/4323560/)）があり、「生成AIによるSaaS足切り・内製化」は2025〜2026年の時流として引用しやすい。

### 3-2. 想定すべき反対意見と備え

| 反対意見 | 備えるべき回答 |
|---|---|
| 開発・保守の属人化、開発者がいなくなったら | ドキュメント整備、Git管理、AIコーディングによる引き継ぎ容易化、保守契約の提示 |
| セキュリティ・バックアップは誰が責任を持つのか | バックアップ設計・最小権限・監査ログを最初から設計に含めて明文化 |
| 現場の非エンジニアが自分で改修できなくなる（kintoneの中核価値の喪失） | 軽微な変更（選択肢追加・項目追加）は設定画面化、改修対応のSLA提示 |
| データ移行は大丈夫か | cli-kintone（無償CLI）でCSV+添付ファイルの一括エクスポート可。標準機能では添付一括不可な点はむしろロックイン論拠 |
| SaaSなら値上げされても運用は安泰では | kintoneは2024年に20〜28%値上げ+最低契約数倍増の**実績**があり、値上げリスクは現実（公式発表ベースで反論可能） |

### 3-3. 中間案・代替案（提案書で比較して潰す or 選ばせる）

1. **プラン変更（スタンダード→ライト、44%減）**: プラグイン・API利用中なら選択不可。素のアプリのみなら最小の打ち手
2. **安価SaaSへの移行**: Zoho CRM 1,680円/人、HubSpot無料CRM〜Starter約1,800円/人（→ §4）
3. **AppSheet**: Google Workspace（Business Starter以上の多く）にCore相当が同梱され実質追加費用なし
4. **段階移行**: 最もフィットしない業務（例: 商談パイプライン）だけ内製化して併走 → 検証後に全面移行・解約

## 4. 代替SaaS CRM/SFA 価格比較（2026年6月・税抜）

10名で使った場合の月額:

```
Zoho CRM Standard   16,800円  （3人まで永久無料枠あり）
kintone Standard    18,000円  （基準）
HubSpot Starter    約18,000円  （無料CRMから開始可。USD建てで変動 ※第三者情報）
Salesforce Starter  30,000円  （※第三者情報）
GENIEE SFA/CRM      34,500円  （10ID単位・最低1年）
eセールスマネージャー 35,000円  （5〜30名限定プラン）
Mazrica Sales       65,000円  （最低10ID・年一括）
ネクストSFA         実質5万円〜 （パック制）
```

- 注意: Mazrica・GENIEEは近年価格改定済みで、Web比較記事の多くが旧料金のまま。HubSpot/Salesforceは公式ページ直接確認不可のため導入前要確認
- **示唆**: 「コスト削減」だけなら Zoho 等への移行でも達成できてしまう。内製提案は **(a) 業界特化のフィット（ヨミ管理＋原稿進捗、ストック契約・解約管理、MEOレポート）** と **(b) ユーザー数非依存の費用構造（増員しても費用が増えない）** をセットで語ることで初めてSaaS移行案に勝てる

## 5. 次のステップ: クライアントへのヒアリング項目

1. 現行プラン・契約ユーザー数・年額（請求書ベースの実額）— 10人未満なら2026年11月の経過措置終了が直近の値上げ要因
2. 有料プラグイン・連携サービスの利用有無と費用
3. **CRM/SFA以外に kintone で回している業務の有無** — 他業務が残ると解約できず削減効果が消える。提案の成否を分ける最重要確認事項
4. 「フィットしない」の具体: どの画面・どの集計・どの帳票で困っているか
5. 商材別の管理実態: ヨミ管理の粒度、MEO解約管理、月次レポート作成の工数
6. 増員計画（ユーザー課金の将来コスト試算用）
7. データ量（顧客件数・商談件数）と添付ファイルの利用状況（移行工数の見積もり用）
